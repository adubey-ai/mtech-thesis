\chapter{Sliding Window Flash Attention}\label{ch:swfa}

\emph{Placement in the stack.} Chapter~\ref{ch:cutlass} established
that skinny attention-score GEMMs are the single most under-utilised
shape class in a transformer forward pass. This chapter attacks the
same bottleneck from the algorithmic side: instead of making the
dense kernel faster, we change the set of blocks it is asked to
compute. The resulting Sliding Window Flash Attention (SWFA) kernel
is the principal theoretical contribution of the thesis, and its
correctness proof (Appendix~\ref{app:proofs_classify}) and
closed-form optimal window (Appendix~\ref{app:proof_optw}) are the
subject of rigorous treatment below. SWFA reappears in
Chapter~\ref{ch:sglang} as the prefill kernel of the SGLang runtime
and in Chapter~\ref{ch:triton} as the cross-validation target for
the Triton port.

\section{Motivation}\label{sec:swfa_motivation}
Attention cost grows quadratically in the sequence length $N$, and at
the context windows used by contemporary production
models ($N \geq 8{,}192$) it is this quadratic term that dictates
both training throughput and decode latency. The Flash Attention
family~\cite{dao2022flashattention,dao2023flashattention2} alleviates
the \emph{memory} side of the quadratic cost by streaming the attention
computation in tiles, but it continues to issue a dense GEMM for every
$B_r \times B_c$ tile---even for tiles that the model is about to
mask out. A large fraction of long-context models restrict attention
to a local window on architectural
grounds~\cite{beltagy2020longformer,zaheer2020bigbird}, permitting
each query at position $i$ to attend only to keys in
$[i-w_l, i+w_r]$. The theoretical cost under this restriction drops
from $\Theta(N^2)$ to $\Theta(Nw)$ with $w = w_l + w_r + 1$, but the
saving is not realised unless the kernel itself is window-aware.

This chapter presents \emph{Sliding Window Flash Attention} (SWFA),
which combines Flash Attention's block-wise computation with an
intelligent preprocessing step that classifies attention blocks as
fully inside, intersecting, or fully outside the window.
Fully-outside blocks are skipped entirely; intersecting blocks use a
vectorised mask. The algorithm reaches up to $65.6\%$ block skipping
on narrow windows without any numerical accuracy loss relative to
vanilla attention.

\section{Background}\label{sec:swfa_background}

\subsection{Flash Attention}\label{sec:fa_bg}
Standard attention, defined by
\begin{equation}
\mathrm{Attention}(Q, K, V) =
\mathrm{softmax}\!\left(\frac{Q K^{\!\top}}{\sqrt{d}}\right) V ,
\end{equation}
is written in three operations---score, softmax, output---that naturally
produce an $N \times N$ score matrix as an intermediate. The observation
behind Flash Attention is that this matrix is only used as an input to
the softmax, and the softmax itself can be computed incrementally. If
queries are partitioned into row tiles of height $B_r$ and keys/values
into column tiles of width $B_c$, a running pair $(m_i, \ell_i)$ of
row-max and row-sum is enough to re-scale previous contributions every
time a new column tile arrives:
\begin{equation}\label{eq:online_softmax}
m_i^{\text{new}} = \max(m_i, \max_j s_{ij}),\quad
\ell_i^{\text{new}} = e^{m_i - m_i^{\text{new}}} \ell_i
                     + \sum_j e^{s_{ij} - m_i^{\text{new}}} ,
\end{equation}
and a matching correction factor is applied to the output accumulator
$O_i$. With this rearrangement the peak HBM residency of the attention
kernel is bounded by the tile sizes rather than by $N^2$, which
collapses the memory footprint from quadratic to linear in the
sequence length without changing the mathematical result up to the
floating-point associativity of the running sum.

\subsection{Sliding-Window Attention}\label{sec:sw_bg}
A symmetric window of size $w$ only keeps attention weights within
distance $w/2$ of the diagonal, i.e. any key position $j$ satisfying
\begin{equation}\label{eq:window}
\max(0, i - w_l) \leq j \leq \min(N-1, i + w_r).
\end{equation}
Existing implementations apply this constraint as an element-wise mask
\emph{after} computing the attention scores---wasteful, because entire
$B_r \times B_c$ blocks are sometimes completely outside the band.
Naive masking incurs the full $\mathcal{O}(N^2)$ FLOP cost; SWFA
reduces it to $\mathcal{O}(Nw)$ by skipping the dense computation on
fully-outside blocks.

\section{Method}\label{sec:swfa_method}

\subsection{Block Classification}\label{sec:swfa_classify}
Given $N$, block sizes $(B_r, B_c)$, and window parameters
$(w_l, w_r)$, partition the attention matrix into $T_r \times T_c$
blocks, where
\begin{equation}
T_r = \left\lceil \frac{N}{B_r} \right\rceil, \qquad
T_c = \left\lceil \frac{N}{B_c} \right\rceil .
\end{equation}
Each block $(r, c)$ is classified into one of three sets:
\begin{description}
    \item[$\mathcal{I}$ (fully inside).] All $(q, k)$ pairs in the
          block satisfy~\eqref{eq:window}; no masking required.
    \item[$\mathcal{X}$ (intersecting).] Some pairs satisfy the
          constraint and some do not; a per-position mask is required.
    \item[$\mathcal{O}$ (fully outside).] No pair satisfies the
          constraint; the block is skipped.
\end{description}

Algorithm~\ref{alg:swfa_classify} performs the classification by
examining the block corners.

\begin{algorithm}[h]
    \caption{Block classification for the sliding window.}
    \label{alg:swfa_classify}
    \KwIn{Sequence length $N$, window $(w_l, w_r)$, block sizes
          $(B_r, B_c)$.}
    \KwOut{Sets $\mathcal{I}$, $\mathcal{X}$, $\mathcal{O}$ of block
           indices.}
    $T_r \leftarrow \lceil N/B_r \rceil,\ T_c \leftarrow \lceil N/B_c
       \rceil$\;
    $\mathcal{I}, \mathcal{X}, \mathcal{O} \leftarrow \emptyset$\;
    \For{$r = 0$ \KwTo $T_r - 1$}{
        row\_start $\leftarrow r\,B_r$,\
        row\_end $\leftarrow \min((r+1)B_r, N)-1$\;
        \For{$c = 0$ \KwTo $T_c - 1$}{
            col\_start $\leftarrow c\,B_c$,\
            col\_end $\leftarrow \min((c+1)B_c, N)-1$\;
            $L_{\text{top}} \leftarrow \max(0, \text{row\_start}-w_l)$\;
            $R_{\text{top}} \leftarrow \min(N-1, \text{row\_start}+w_r)$\;
            $L_{\text{bot}} \leftarrow \max(0, \text{row\_end}-w_l)$\;
            $R_{\text{bot}} \leftarrow \min(N-1, \text{row\_end}+w_r)$\;
            outside $\leftarrow (\text{col\_end} < L_{\text{top}})$ or
                               $(\text{col\_start} > R_{\text{bot}})$\;
            inside  $\leftarrow (\text{col\_end} \le R_{\text{top}})$ and
                               $(\text{col\_start} \ge L_{\text{bot}})$\;
            \uIf{outside}{$\mathcal{O} \leftarrow
                \mathcal{O} \cup \{(r,c)\}$}
            \uElseIf{inside}{$\mathcal{I} \leftarrow
                \mathcal{I} \cup \{(r,c)\}$}
            \Else{$\mathcal{X} \leftarrow
                \mathcal{X} \cup \{(r,c)\}$}
        }
    }
    \Return $\mathcal{I}, \mathcal{X}, \mathcal{O}$\;
\end{algorithm}

\subsection{Correctness of the Classifier}\label{sec:swfa_classify_proof}
\begin{lemma}[Corner-check sufficiency]\label{lem:corner}
Let $B = [r_0, r_1] \times [c_0, c_1]$ be an axis-aligned block of the
attention matrix, and let
$W = \{(i, j) : i - w_l \le j \le i + w_r\}$ denote the window band.
Then:
\begin{enumerate}
    \item[\textup{(i)}]
    $B \cap W = \emptyset \iff c_1 < r_0 - w_l \text{ or } c_0 > r_1 + w_r$;
    \item[\textup{(ii)}]
    $B \subseteq W \iff c_1 \le r_0 + w_r \text{ and } c_0 \ge r_1 - w_l$.
\end{enumerate}
\end{lemma}
\begin{proof}
The window is the strip between the two lines $j = i - w_l$ (lower
boundary) and $j = i + w_r$ (upper boundary). Because these boundaries
are monotone in $i$, the minimum of $j - i$ over $B$ is attained at
$(r_1, c_0)$ and the maximum at $(r_0, c_1)$. The block lies entirely
outside $W$ iff the minimum of $j - (i + w_r)$ is positive over $B$
or the maximum of $j - (i - w_l)$ is negative, which are exactly the
two conditions stated; similarly, the block lies entirely inside $W$
iff both extrema of $j - i$ fall inside $[-w_l, w_r]$. Clipping at
$[0, N-1]$ does not affect the inequalities because the window
intersected with $[0, N-1]^2$ is a subset of the unclipped band.
\end{proof}

Lemma~\ref{lem:corner} justifies the $\mathcal{O}(T_r T_c)$ classifier:
only four corner checks are required per block, giving an
$\mathcal{O}((N/B)^2)$ classification cost that is dominated by the
$\mathcal{O}(N w / B)$ cost of the non-skipped blocks.

\subsection{Vectorised Mask Generation}\label{sec:swfa_mask}
For a block $(r, c)$, define the block diagonal offset
$\delta_{rc} = c B_c - r B_r$. A local position $(i_\ell, j_\ell)$
inside the block corresponds to relative position
$\mathrm{rel} = j_\ell - i_\ell$, which must be masked whenever
\begin{equation}
    \mathrm{rel} > w_r + \delta_{rc}
    \quad\text{or}\quad
    \mathrm{rel} < -w_l + \delta_{rc}.
\end{equation}
Define
\begin{equation}
    d_{\text{right}} = \lfloor w_r + \delta_{rc} \rfloor + 1, \qquad
    d_{\text{left}}  = \lfloor -w_l + \delta_{rc} \rfloor - 1.
\end{equation}
The mask can then be generated in a single shot as
\begin{equation}\label{eq:mask}
    M_{rc} =
    \mathrm{triu}(\mathbf{1}_{B_r \times B_c}, d_{\text{right}})
    \vee
    \mathrm{tril}(\mathbf{1}_{B_r \times B_c}, d_{\text{left}}),
\end{equation}
which replaces the nested $\mathcal{O}(B_r B_c)$ loop by a single
vectorised call; the procedure is summarised as
Algorithm~\ref{alg:swfa_mask}.

\begin{algorithm}[h]
    \caption{Efficient mask generation for an intersecting block.}
    \label{alg:swfa_mask}
    \KwIn{Block shapes $(B_r, B_c)$, block indices $(r, c)$, window
          $(w_l, w_r)$.}
    \KwOut{Mask $M \in \{0, -\infty\}^{B_r \times B_c}$.}
    $\delta \leftarrow c B_c - r B_r$\;
    $d_{\text{right}} \leftarrow \lfloor w_r + \delta \rfloor + 1$\;
    $d_{\text{left}}  \leftarrow \lfloor -w_l + \delta \rfloor - 1$\;
    both $\leftarrow (d_{\text{right}} \le B_r) \wedge
                      (d_{\text{left}} \ge -B_c)$\;
    \uIf{both}{
        $M_R \leftarrow \mathrm{triu}(\mathbf{1}, d_{\text{right}})$,
        $M_L \leftarrow \mathrm{tril}(\mathbf{1}, d_{\text{left}})$,
        $M_{\text{bool}} \leftarrow M_R \vee M_L$\;
    }
    \uElseIf{$d_{\text{right}} \le B_r$}{
        $M_{\text{bool}} \leftarrow \mathrm{triu}(\mathbf{1},
                                                  d_{\text{right}})$\;
    }
    \uElseIf{$d_{\text{left}} \ge -B_c$}{
        $M_{\text{bool}} \leftarrow \mathrm{tril}(\mathbf{1},
                                                  d_{\text{left}})$\;
    }
    \Else{$M_{\text{bool}} \leftarrow \mathbf{0}$}
    $M \leftarrow \mathbf{0}$;\ $M[M_{\text{bool}}] \leftarrow -\infty$\;
    \Return $M$\;
\end{algorithm}

\subsection{Sliding Window Flash Attention Kernel}\label{sec:swfa_kernel}
Algorithm~\ref{alg:swfa} gives the complete forward pass, which reuses
the Flash Attention online softmax on top of the block classification.

\begin{algorithm}[h]
    \caption{Sliding Window Flash Attention (forward pass).}
    \label{alg:swfa}
    \KwIn{$Q \in \mathbb{R}^{B \times H \times N \times d}$,
          $K, V \in \mathbb{R}^{B \times H \times N \times d_v}$,
          window $(w_l, w_r)$, block sizes $(B_r, B_c)$.}
    \KwOut{$O \in \mathbb{R}^{B \times H \times N \times d_v}$.}
    $\mathcal{I}, \mathcal{X}, \mathcal{O} \leftarrow
        \textsc{ClassifyBlocks}$\;
    Partition $Q, K, V$ into $\{Q_r\}, \{K_c\}, \{V_c\}$\;
    \For{$r = 0$ \KwTo $T_r - 1$}{
        $O_r \leftarrow \mathbf{0},\ m_r \leftarrow -\infty,\
         \ell_r \leftarrow 0$\;
        \For{$c = 0$ \KwTo $T_c - 1$}{
            \If{$(r, c) \in \mathcal{O}$}{\textbf{continue}}
            $S_{rc} \leftarrow Q_r K_c^{\!\top} / \sqrt{d}$\;
            \If{$(r, c) \in \mathcal{X}$}{
                $M_{rc} \leftarrow \textsc{GenerateMask}(\dots)$;\
                $S_{rc} \leftarrow S_{rc} + M_{rc}$\;
            }
            $m_r^{\text{new}} \leftarrow \max(m_r, \max(S_{rc}))$\;
            $\mathrm{corr} \leftarrow \exp(m_r - m_r^{\text{new}})$\;
            $P_{rc} \leftarrow \exp(S_{rc} - m_r^{\text{new}})$\;
            $\ell_r \leftarrow \mathrm{corr}\,\ell_r + \sum P_{rc}$\;
            $O_r \leftarrow \mathrm{corr}\,O_r + P_{rc} V_c$\;
            $m_r \leftarrow m_r^{\text{new}}$\;
        }
        $O_r \leftarrow O_r / (\ell_r + \varepsilon)$;\ write into
        $O$\;
    }
    \Return $O$\;
\end{algorithm}

\subsection{Backward Pass}\label{sec:swfa_backward}
The backward pass uses the fact that the online softmax keeps only
$(m_r, \ell_r, O_r)$ per row block. To recompute the softmax during
backpropagation, we re-run the forward loop with the same block
classification, but this time we
(i) recompute $S_{rc}$ on the fly;
(ii) use the stored $(m_r, \ell_r)$ to obtain $P_{rc}$;
(iii) compute $\mathrm{d}V_c \mathrel{+}= P_{rc}^{\top}\,\mathrm{d}O_r$,
$\mathrm{d}P_{rc} = \mathrm{d}O_r V_c^{\top}$,
$\mathrm{d}S_{rc} = P_{rc} \odot (\mathrm{d}P_{rc} - \rho_r)$ where
$\rho_r = \sum_c P_{rc} \odot \mathrm{d}P_{rc}$.
Outside blocks are skipped because their forward contribution is zero;
intersecting blocks reapply the same mask. Pseudocode is given in
Algorithm~\ref{alg:swfa_backward}.

\begin{algorithm}[h]
    \caption{Sliding Window Flash Attention (backward pass).}
    \label{alg:swfa_backward}
    \KwIn{$Q, K, V$; saved $\{m_r, \ell_r, O_r\}$;
          $\mathrm{d}O$; sets $\mathcal{I}, \mathcal{X}, \mathcal{O}$.}
    \KwOut{$\mathrm{d}Q, \mathrm{d}K, \mathrm{d}V$.}
    \For{$r = 0$ \KwTo $T_r - 1$}{
        $\rho_r \leftarrow
            \sum_c P_{rc}\odot (\mathrm{d}O_r V_c^\top)$\;
        \tcp*[l]{first sweep: accumulate $\rho_r$ on the fly}
    }
    \For{$r = 0$ \KwTo $T_r - 1$}{
        \For{$c = 0$ \KwTo $T_c - 1$}{
            \If{$(r, c) \in \mathcal{O}$}{\textbf{continue}}
            $S_{rc} \leftarrow Q_r K_c^\top / \sqrt{d}$\;
            \If{$(r, c) \in \mathcal{X}$}{
                $S_{rc} \leftarrow S_{rc} + M_{rc}$\;}
            $P_{rc} \leftarrow e^{S_{rc} - m_r} / \ell_r$\;
            $\mathrm{d}V_c \mathrel{+}= P_{rc}^\top \mathrm{d}O_r$\;
            $\mathrm{d}P_{rc} \leftarrow \mathrm{d}O_r V_c^\top$\;
            $\mathrm{d}S_{rc} \leftarrow
                P_{rc}\odot (\mathrm{d}P_{rc} - \rho_r)$\;
            $\mathrm{d}Q_r \mathrel{+}=
                \mathrm{d}S_{rc} K_c / \sqrt{d}$\;
            $\mathrm{d}K_c \mathrel{+}=
                \mathrm{d}S_{rc}^\top Q_r / \sqrt{d}$\;
        }
    }
    \Return $\mathrm{d}Q, \mathrm{d}K, \mathrm{d}V$\;
\end{algorithm}

The backward pass visits the same block set as the forward pass, so
its speedup factor over vanilla backward is identical: up to $65.6\%$
skipped blocks on narrow windows.

\subsection{Complexity}\label{sec:swfa_complexity}
For a sequence of length $N$, window $w$, and block size $B$:
\begin{itemize}
    \item Total blocks: $(N/B)^2$.
    \item Blocks inside the band: $\approx 2 (N/B)(w/B)$.
    \item Blocks skipped: $(N/B)^2 - 2(N/B)(w/B)$, giving a
          theoretical speed-up of $1 - \tfrac{2w}{N}$ when $w \ll N$.
\end{itemize}
For $N=128$, $w=4$, $B=16$, $48$ of $64$ blocks ($75\%$) are skipped.
The memory footprint matches Flash Attention's $\mathcal{O}(N)$. A
formal block-count lemma is given in Appendix~\ref{app:proofs_block}.

\section{Optimal Window Size}\label{sec:swfa_optimal}

\subsection{Cost Model}\label{sec:swfa_cost}
The total cost of using a sliding window is modelled as
\begin{equation}\label{eq:loss}
\mathcal{L}(w) = \alpha\, C(w) + \beta\, M(w) + \gamma\, P(w),
\end{equation}
with
\begin{align*}
C(w) &= \kappa N w d & \text{(computation, seconds)} \\
M(w) &\approx M_0    & \text{(memory, constant in $w$)} \\
P(w) &= \frac{2 N A_0 e^{-\lambda w/2}}{1 - e^{-\lambda}}
                    & \text{(performance loss, dimensionless)}
\end{align*}
where the performance term assumes an exponential attention-decay
model $A_{ij} = A_0 e^{-\lambda|i-j|}$ and the computation term uses
the $\kappa$ seconds-per-FLOP constant of the underlying GEMM kernel.
The empirical justification for $A_{ij} = A_0 e^{-\lambda|i-j|}$ is in
Appendix~\ref{app:proof_decay}.

\subsection{Convexity}\label{sec:swfa_convex}
\begin{theorem}\label{thm:swfa_convex}
$\mathcal{L}(w)$ is strictly convex for $w > 0$.
\end{theorem}
\begin{proof}
The computational cost is linear in $w$. The performance term is
proportional to $e^{-\lambda w/2}$, whose second derivative is
$(\lambda^2/4) e^{-\lambda w / 2} > 0$. The memory term is constant in
$w$. Hence $\mathcal{L}''(w) > 0$ for all $w > 0$, proving strict
convexity. A complete proof, including the constants and the boundary
behaviour at $w = 0$, is in Appendix~\ref{app:proof_convex}.
\end{proof}

\subsection{Optimal Window}\label{sec:swfa_opt}
\begin{theorem}\label{thm:swfa_optw}
The minimiser of~\eqref{eq:loss} is
\begin{equation}\label{eq:optimal_w}
w^{\star} = \frac{2}{\lambda}
  \ln\!\left(\frac{\gamma A_0 \lambda}
                   {\alpha \kappa d (1 - e^{-\lambda})}\right).
\end{equation}
\end{theorem}
\begin{proof}
Differentiating $\mathcal{L}$ with respect to $w$,
\[
\frac{d\mathcal{L}}{dw} =
\alpha \kappa N d -
\frac{\gamma N A_0 \lambda e^{-\lambda w / 2}}{1 - e^{-\lambda}}.
\]
Setting this to zero yields
$e^{-\lambda w^{\star}/2} = \alpha \kappa d (1 - e^{-\lambda})
/ (\gamma A_0 \lambda)$, and taking logarithms
gives~\eqref{eq:optimal_w}. Theorem~\ref{thm:swfa_convex} guarantees
that $w^{\star}$ is the unique global minimum. A full proof, with
details of the boundary projection onto $[1, N-1]$, is given in
Appendix~\ref{app:proof_optw}.
\end{proof}

In practice, $w^{\star}$ must be projected onto $[1, N-1]$.
Corollaries follow immediately: $w^{\star} \uparrow$ as
$\alpha \downarrow$ (cheap compute); $w^{\star} \downarrow$ as
$\gamma \downarrow$ (accuracy matters less); $w^{\star}$ decreases as
the embedding dimension $d$ grows because each token becomes more
informative.

\section{Summary}\label{sec:swfa_summary}
SWFA combines Flash Attention's streaming block computation with an
explicit block-sparsity step, yielding:
\begin{itemize}
    \item up to $65.6\%$ reduction in computed attention blocks;
    \item sub-$10^{-4}$ error against the reference attention;
    \item $50$--$59\%$ end-to-end training throughput improvement on
          GPT-2-Medium when used with DeepSpeed/FSDP;
    \item a closed-form optimal window size under an exponential
          decay model, with a strictly convex loss that admits a
          unique minimiser.
\end{itemize}
Remaining work includes a CUDA/Triton port (sketched in
Chapter~\ref{ch:triton}), an efficient backward-pass kernel
(Algorithm~\ref{alg:swfa_backward}), and integration into the serving
stack of Chapter~\ref{ch:sglang}.
